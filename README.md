## What I build

I design **AI-native products, agent workflows and production backends** that solve practical problems without turning the system into a black box.

My work combines multi-agent architecture, repository-backed project memory, automation, Telegram products and dependable Python services. The common thread is simple: useful AI needs clear contracts, observable decisions and software that survives contact with reality.

> **Currently building:** [Community Mini App](https://github.com/AlexOxytocin/community_bot) — a Telegram-based mutual-help product with tasks, internal credits, reputation, moderation and an auditable transaction model.

## How I work

- **Make decisions explicit.** Architecture, risk and acceptance criteria belong in durable artifacts, not only in chat history.
- **Keep humans in control.** Agents can explore and implement; important decisions still need evidence, review and a clear owner.
- **Design for operations.** Tests, migrations, observability, recovery and safe deployment are part of the product.
- **Automate the boring parts.** Good automation removes repetition while keeping failures visible and recoverable.
